One engine, any system

Parts & quantities

Every node holds numeric quantities — glucose, population, whatever your system tracks. Every connection can move them.

Real rules, not scripts

Diffusion, active transport, formulas — the same small rule set drives a cell's metabolism and a network's supply routes. Nothing is scripted per level.

Goals are properties, not triggers

Win conditions are things like "ATP stays above 3 for 10 ticks" or "the network stays a tree" — checked against what's actually happening, every tick.

Every level is a text file

No hidden logic. A level is a part list, a starting layout, and a goal — readable, editable, moddable.
